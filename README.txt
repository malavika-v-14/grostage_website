GROSTAGE GSAP UPGRADE
1) Copy the lib/, components/ and app/ folders over your project (merge them, and replace when asked).
2) In the project folder run:   npm i gsap @gsap/react lenis
   (needs gsap 3.13 or newer; SplitText is included free)
3) npm run dev
4) Optional cleanup: delete components/SiteLoader.jsx (no longer used). Keep Reveal.jsx, the home page still uses it.
